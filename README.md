# 🎧 Assist Relay 2

<img width="720" height="1603" alt="assist_relay_720" src="https://github.com/user-attachments/assets/15d7189e-fb37-4bb5-bab7-3ad104bc3ebe" />



**Assist Relay 2** — небольшое Android-приложение, которое позволяет запускать сторонних голосовых ассистентов с помощью длительного нажатия на blooetuth наушниках.

Приложение создано как обходное решение проблемы [LibrePods #868](https://github.com/librepods-org/librepods/issues/868), из-за которой вместо запуска выбранного голосового помощника Android может открывать настройки ассистента.

### ✨ Возможности

- 🎧 **Активация через blooetuth наушники** — запуск голосового помощника длительным удержанием элемента управления на наушниках.
- 🎙️ **Поддержка сторонних ассистентов** — возможность запускать не только ChatGPT, но и другие приложения, поддерживающие соответствующие механизмы Android.
- 🔊 **Звуковое подтверждение** — воспроизведение сигнала активации в наушниках.
- ⚡ **Запуск через Root** — использование системной команды Android для вызова голосового интерфейса.
- 🔄 **Резервные способы запуска** — попытка использовать стандартный Android Intent или открыть выбранное приложение, если основной способ недоступен.

### 🔧 Как это работает

При длительном нажатии на blooetuth наушник приложение отправляет системное событие `ACTION_VOICE_COMMAND`.

На некоторых устройствах этот механизм некорректно работает со сторонними ассистентами.

**Assist Relay 2** обрабатывает это событие и выполняет следующую последовательность:

1. Получает `ACTION_VOICE_COMMAND`.
2. Воспроизводит звуковой сигнал активации.
3. Пытается выполнить команду через Root:

   `su -c "cmd voiceinteraction show"`

4. Если Root недоступен или команда завершается ошибкой, пробует запустить ассистента через `ACTION_ASSIST`.
5. Если предыдущие способы не сработали, пытается открыть выбранное пользователем приложение.

Это позволяет обойти проблему с запуском сторонних голосовых ассистентов.

### 📱 Совместимость

**Проверенная конфигурация:**

| Компонент | Значение |
|---|---|
| Устройство | Xiaomi 14 |
| Прошивка | Xiaomi.eu |
| Система | HyperOS 2.0.211.0 |
| Root | Да |
| Результат | Работает на указанной конфигурации |

**Важно:** приложение протестировано на устройстве с Root-доступом. Работа на других прошивках, смартфонах и версиях Android пока не подтверждена.

### 🚀 Установка и настройка

1. Установите Assist Relay 2.
2. Предоставьте Root-доступ при необходимости.
4. Настройте приложение для обработки голосовых команд.
4. В приложение наушников назначьте действие **Digital Assistant** на длительное нажатие.
5. Проверьте запуск голосового помощника.

Некоторые действия могут потребовать дополнительных настроек Android или HyperOS.

- Для основного способа запуска необходим Root-доступ.
- Резервные способы запуска зависят от поддержки Android и выбранного ассистента.
- Совместимость с другими устройствами и прошивками не гарантируется.
- Assist Relay 2 является независимым обходным решением.
